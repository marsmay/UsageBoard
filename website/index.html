一分钟安装

需要 macOS 13.0 或更高版本

1

通过 Homebrew 安装

brew install --cask marsmay/usageboard/usageboard
2

首次打开时若提示"无法验证开发者"，在"系统设置 → 隐私与安全性"中点击"仍要打开"，或执行：

xattr -cr /Applications/UsageBoard.app
3

在设置中添加并启用插件，填入对应服务的凭据，用量即刻出现在菜单栏。
