UsageBoard 插件编写说明

插件是一个 Python 脚本。UsageBoard 会定时执行脚本，读取 stdout 中的 JSON，并把返回的用量项目渲染成进度条。

基本规则

  • 脚本建议使用 #!/usr/bin/env python3。
  • UsageBoard 不通过 shell 执行脚本，会直接调用 Python 运行 .py 文件。
  • 插件配置参数通过命令行传入，格式为 --usageboard-param KEY=value。
  • 脚本必须向 stdout 输出一个 JSON 对象。stderr 可用于调试，但不会作为用量数据解析。
  • 脚本退出码非 0、超时、stdout 不是合法 JSON，都会在对应插件卡片上显示错误。

声明配置参数

在脚本开头注释中放入固定块 UsageBoardPlugin。UsageBoard 添加插件或刷新元数据时会读取这个注释块，并在设置界面自动生成表单。

#!/usr/bin/env python3
# UsageBoardPlugin:
# {
#   "name": "Example",
#   "description": "查询某个服务的用量",
#   "description@zh-Hans": "查询某个服务的用量",
#   "description@en": "Query usage for a service",
#   "parameters": [
#     {
#       "name": "API_KEY",
#       "label": "Api Key",
#       "label@zh-Hans": "Api Key",
#       "label@en": "API Key",
#       "type": "string",
#       "required": true,
#       "placeholder": "Service API Key"
#     },
#     {
#       "name": "STAT_PERIOD",
#       "label": "统计周期",
#       "label@zh-Hans": "统计周期",
#       "label@en": "Stats Period",
#       "type": "choice",
#       "required": false,
#       "defaultValue": "7d",
#       "options": [
#         {"label": "7 天", "label@zh-Hans": "7 天", "label@en": "7 days", "value": "7d"},
#         {"label": "30 天", "label@zh-Hans": "30 天", "label@en": "30 days", "value": "30d"}
#       ]
#     }
#   ]
# }
# /UsageBoardPlugin

涉及展示的插件元数据字段支持同级多语言字段，例如 name@zh-Hans、name@en、description@zh-Hans、description@en、label@zh-Hans、label@en、placeholder@zh-Hans、placeholder@en。当前语言对应字段缺失或为空时，UsageBoard 会回退到不带语言后缀的基础字段。

元数据字段

字段 说明
name 插件名称。
icon 可选。图标图片 URL，显示在插件卡片标题前。图片会被内存缓存，首次加载后不再重复下载。不设置时显示默认拼图图标。
description 插件描述，显示在设置页插件详情中。
parameters 参数定义数组，每项对应设置页中的一个表单字段。

参数字段

字段 说明
name 参数键名。脚本会收到 --usageboard-param name=value。
label 设置界面显示名称；不传时使用 name。
type 支持 string、secret、integer、boolean、choice、directory、file。
required 是否必填。必填项为空时插件不能启用。
placeholder 输入框占位提示。
defaultValue 添加插件时自动填入的默认值。
options choice 类型使用，每项包含 label 和 value。
directory / file 设置界面显示路径输入框和选择器。directory 只能选择文件夹，file 只能选择文件。

读取参数

内置插件复用同目录 _common.py 的 parse_usageboard_params 和 app_language。独立用户插件可随脚本提供该模块；下例为无需公共模块的独立实现。

import sys

def parse_usageboard_params(argv):
    values = {}
    index = 0
    while index < len(argv):
        if argv[index] == "--usageboard-param" and index + 1 < len(argv):
            key_value = argv[index + 1]
            if "=" in key_value:
                key, value = key_value.split("=", 1)
                values[key] = value
            index += 2
        else:
            index += 1
    return values

params = parse_usageboard_params(sys.argv[1:])
api_key = params.get("API_KEY", "")

UsageBoard 会额外传入当前 app 语言参数：--usageboard-param USAGEBOARD_LANGUAGE=zh-Hans 或 --usageboard-param USAGEBOARD_LANGUAGE=en。脚本应读取这个保留参数，并直接返回对应语言的展示文本。

返回数据格式

stdout 上限为 8 MiB，stderr 最多保留 64 KiB。超时、取消或 stdout 超限会终止插件进程；Python 执行禁用字节码缓存，避免修改 app 包。非空顶层 error 优先视为失败，即使同时返回成功字段。

插件输出的 JSON 顶层对象必须包含 updatedAt 和 items。

{
  "updatedAt": "2026-04-29T00:00:00Z",
  "items": [
    {
      "id": "requests",
      "name": "Requests",
      "used": 1200,
      "limit": 1500,
      "displayStyle": "ratio",
      "resetAt": "2026-04-29T05:00:00Z",
      "status": "normal",
      "color": "blue"
    }
  ],
  "badge": "PRO",
  "chart": {
    "kind": "line",
    "period": "30d",
    "bucketUnit": "day",
    "buckets": [
      {
        "id": "2026-05-01",
        "label": "05-01",
        "segments": [
          {"model": "glm-4.5", "tokens": 1200},
          {"model": "glm-4.6", "tokens": 800}
        ]
      }
    ],
    "message": null
  }
}

用量项目字段

字段 说明
id 项目稳定 ID。建议只使用字母、数字、连字符或下划线。
name 界面显示名称。
used 已使用数量。
limit 总额度。进度条按 used / limit 计算，并限制在 0...1。
displayStyle percent 显示百分比，例如 80%；ratio 显示数字占比，例如 1200/1500。
resetAt ISO 8601 时间字符串，例如 2026-04-29T05:00:00Z。缺失或过期时界面显示 --。
status 支持 normal、warning、critical、unknown。
color 可选。控制进度条颜色，支持 blue、yellow、orange、red、green；不传默认蓝色。

可选图表字段

顶层 chart 字段用于在插件卡片底部展示 token 统计图。当前支持 kind: "line"，每个 bucket 是一个时间点，每个 segment 是一个模型序列值。

字段 说明
period 统计周期标识，例如 7d、30d。
bucketUnit 时间桶单位，支持 hour 或 day。
buckets[].segments[] 模型分段，包含 model 和 tokens。
message 可选提示文案，统计数据为空或不可用时显示。

建议插件在查询失败时仍返回一个合法 JSON，并把错误写成一个 status: "critical" 的项目；这样用户能在 UsageBoard 界面里直接看到原因。
